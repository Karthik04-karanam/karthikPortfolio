## 🚀 How to Preview & Deploy

### Previewing Locally
Double-click [`index.html`](index.html) in your file explorer to open it directly in any web browser, or use the VS Code Live Server extension.

### Free 1-Click Deployment Options
- **GitHub Pages**: Push repository to GitHub, go to **Settings** > **Pages** > Select `main` branch `/root` > Save.
- **Vercel / Netlify**: Import your GitHub repository to Vercel or drag-and-drop the directory into Netlify Drop for instant worldwide hosting.
